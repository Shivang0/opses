# OPSES Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the OPSES demo — an in-house agent that ingests a developer's agentic-AI telemetry and, running Gemma locally on the CISO box, produces per-developer AI-hygiene + risk findings with cited compliance evidence, without any prompt leaving the building.

**Architecture:** Endpoint captures Cursor/Claude Code telemetry → masks + E2E-encrypts locally → Cloudflare Durable Object relays ciphertext → CISO box decrypts → Gemma-local analyzer produces findings → mapped to a Vultr-built (public-regulation) citation rulebook → rendered report. Phased demo-first: the analyzer + report are built on **synthetic data first** so the hero demo exists by end of Phase 1, then real capture/transport/citations are wired underneath.

**Tech Stack:** Python 3.11 (endpoint, CISO analyzer, regbook), TypeScript + Wrangler (Cloudflare Worker/Durable Object), Gemma 4 via **Ollama** (local HTTP API), Vultr Serverless Inference (public regs only), **PyNaCl** (libsodium SealedBox) for E2E encryption, `LangGuard-AI/cursor-otel-hook` (Cursor capture), Claude Code transcripts + hooks + config files (Claude Code capture).

**Note on format:** This is a hackathon spike. Pure-logic units (analyzers, encryption, schema) get real tests; integration-heavy tasks (Cloudflare, Ollama, Vultr, Claude Code hooks) use exact build+verify commands with expected output instead of fictional unit tests. DRY, YAGNI, commit after every task.

## File Structure

```
opses/
  shared/schema.py         # normalized UsageEvent + ConfigManifest + Finding dataclasses (the contract everything speaks)
  endpoint/
    capture_claude.py      # read ~/.claude transcripts + config files -> raw events + manifest
    mask.py                # redact PII/secrets locally BEFORE anything leaves the machine
    encrypt.py             # PyNaCl SealedBox: encrypt masked batch with CISO public key
    send.py                # POST ciphertext to the Cloudflare Worker
  transport/               # Cloudflare Worker + Durable Object (TypeScript)
    src/worker.ts          # routes /ingest/:employee and /pull/:employee to the DO
    src/employee_do.ts     # one Durable Object per employee: ordered ciphertext buffer
    wrangler.toml
  ciso/
    receive.py             # pull ciphertext from CF, decrypt with CISO secret key
    analyzer/
      mcp_bloat.py         # finding: too many MCPs / startup context cost
      claudemd_bloat.py    # finding: oversized CLAUDE.md (+ Gemma-generated trim)
      hook_exfil.py        # finding: hook/command exfiltrating secrets to a URL
      pii_leak.py          # finding: PII/secret sent to a cloud model
    gemma.py               # thin Ollama client for local Gemma reasoning
    report.py              # render per-dev report + CISO rollup (generated HTML, not a live dashboard)
  regbook/
    build_rulebook.py      # Vultr Serverless over PUBLIC reg text -> cited control library
    controls.json          # generated: {control_id, requirement, what_to_check, citation}
    corpus/                # bundled PUBLIC snippets: EU AI Act Art.10, ISO 42001, NIST RMF MAP, cost
  demo/
    synth.py               # generate a synthetic "employee" (events + manifest) with the 4 planted issues
    plant_machine.sh       # set up a real Claude Code machine with the 4 planted issues
    run_demo.py            # the scripted "catch" + pull-the-cable sequence
  samples/                 # synthetic output committed for offline dev
  tests/
  pyproject.toml
  README.md
```
